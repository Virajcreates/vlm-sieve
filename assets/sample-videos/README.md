# Sample Benchmark Videos

This directory contains sample video inputs used to evaluate
vlm-sieve's video preprocessing and storyboard generation.

| Video | Description |
|---|---|
| ring-shovel-identification.webm | Ring security footage used for multi-angle object identification testing. |
| vivint-doorbell-sample.mp4 | Vivint doorbell footage used for short-duration video benchmarking. |

These samples demonstrate how vlm-sieve processes real-world
security footage before passing visual information to VLMs.
